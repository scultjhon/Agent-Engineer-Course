# Agent Engineer Course

An open, practical learning path for building reliable agent systems. The course is published as a MkDocs Material site and is designed to work well on desktop and mobile.

## Local preview

```bash
python -m pip install mkdocs-material
mkdocs serve
```

## Scope

This repository uses generic examples such as `sample-app` and `demo-repo`. It contains no personal projects, credentials, private paths, or account-specific details.
