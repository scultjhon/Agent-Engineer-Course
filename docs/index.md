# Agent Engineer Course

Welcome to an open, continuously expandable course on enterprise agent engineering.

Use the sidebar to jump directly to a lesson, search the full site, or follow the [roadmap](roadmap.md). Each lesson combines a mental model, practical commands or interfaces, common failure modes, and a small exercise.

## Learning loop

1. Read the lesson overview.
2. Run the smallest safe experiment in `labs/`.
3. Record what happened and why.
4. Connect the concept to source code, deployment, evaluation, or security.

## Progress

The first 11 lessons establish the foundations. Later modules add source study, model engineering, evaluation, observability, security, and a final mini enterprise agent platform.
