## 学习方式

1. 先理解本课的工程问题和心智模型。
2. 阅读对应 Codex、OpenCode、Kimi Code 或公开 Agent 机制的源码/资料映射。
3. 完成最小安全实验。
4. 观察日志、退出码、网络、权限或资源状态，而不是只看模型输出。
5. 将知识连接到 Agent 开发、部署、调试、评测与安全。

## 课程主线

基础阶段目前完成前 11 课。后续继续扩展 Kubernetes 安全、Agent 编排、MCP/Skills、Coding Agent 源码、自研 Agent、Hugging Face 与模型调试、Eval/Trace/Observability，以及最终的 Mini Enterprise Agent Platform。
