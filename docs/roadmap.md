# Roadmap

| Stage | Focus | Outcome |
|---|---|---|
| 1 | Agent and engineering fundamentals | Explain and debug an agent loop |
| 2 | Coding-agent source study | Trace tools, sessions, permissions, and state |
| 3 | Build an agent service | Ship a small API with tests and guardrails |
| 4 | MCP and Skills | Add controlled capabilities and reusable workflows |
| 5 | Enterprise deployment | Operate containers, queues, Kubernetes, and TLS |
| 6 | Model engineering | Use open models, datasets, inference, and RAG |
| 7 | Eval, trace, security | Measure quality and contain risk |
| 8 | Final project | Assemble a mini enterprise agent platform |

New daily material should become a versioned Markdown page, be added to `mkdocs.yml`, and receive a short link from the course index.
